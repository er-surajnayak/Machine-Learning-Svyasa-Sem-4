Support Vector
Machine

SVM finds the fairest possible boundary between classes — not just any line that separates them, but the one with the widest breathing room. Add the kernel trick and it conquers data no straight line could ever separate.

01 · The concept

Intuition & analogy

Every classifier draws a line between classes. But most just need any line. SVM asks a harder question: which line is the most confident separator? The answer is the one that stays as far as possible from both classes — the maximum-margin hyperplane.

Analogy — The fairest aisle in the cafeteria: Two rival groups sit on opposite sides. You must draw a line between them. You could draw it 1 cm from Group A — unfair and unstable. The fairest line maximises the gap from both groups equally. The students closest to this line are the "support vectors" — remove anyone else and the line stays. SVM finds this maximum-margin boundary.
Analogy — Drawing with a fat marker: A thin pen can draw many valid separating lines. But a fat marker — only the widest possible gap fits the marker's width. SVM finds the widest marker that fits between classes. The width is the margin.
Most classifiers

Find any separating boundary. Multiple valid answers. No guarantee of generalisation quality.

SVM

Finds the maximum-margin boundary. Unique optimal solution. Maximises the distance to the nearest training points.

Why it matters

Wider margin = more robust to new data = better generalisation. SVM handles the hardest points most carefully.

02 · The boundary

The hyperplane

In 2D, SVM draws a line. In 3D, a plane. In higher dimensions, a hyperplane — a flat subspace dividing feature space into two half-spaces, one per class.

Decision hyperplane: w · x + b = 0

Prediction rule: If w · x + b ≥ +1 → Class +1 If w · x + b ≤ −1 → Class −1

where w = weight vector · x = input features · b = bias

Think of it like maximising the gap between two parallel rulers — one touching the nearest Class A point, one touching the nearest Class B point. SVM finds the orientation and position that makes this gap as wide as possible while respecting both constraints.

03 · The key players

Support vectors & the margin

Not all training points matter equally. Only a tiny subset — the support vectors — actually define the boundary. Delete any other point and the hyperplane doesn't move.

Analogy — Load-bearing walls: Most walls in a building are decorative — remove them, structure stands. But load-bearing walls are critical — remove one and everything shifts. Support vectors are SVM's load-bearing walls: they're the training points sitting exactly on the margin boundaries, holding the hyperplane in place.

05 · Real-world SVM

Soft margin & the C parameter

Hard margin SVM requires perfectly linearly separable data — one outlier and it fails. Real data is messy. Soft margin SVM allows some points to violate the margin, controlled by the hyperparameter C.

Analogy — The tolerant referee: Hard margin calls a foul for any contact at all — perfect but impractical. Soft margin allows minor fouls if it keeps the game flowing better. C is how strict this referee is. High C = very strict (few violations). Low C = lenient (allows more violations for a wider, stable boundary).

06 · The magic move

The kernel trick

What if data isn't linearly separable? SVM's secret weapon is the kernel trick — it implicitly maps data to a higher-dimensional space where a linear hyperplane does exist, without ever computing the transformation explicitly.

Analogy — Coins on a table: Red and blue coins mixed on a flat table — no straight line can separate them (concentric circles). Bang the table — they briefly fly up into 3D. In that 3D moment, you slip a flat paper between them perfectly. The kernel trick does this lift mathematically without computing the 3D coordinates.
Why it's a "trick": Computing high-dimensional coordinates is expensive — sometimes infinite-dimensional. But the kernel K(xᵢ, xⱼ) computes the dot product in that high-D space directly from original features — no explicit transformation needed.
K(xᵢ, xⱼ) = φ(xᵢ) · φ(xⱼ)

Computes the inner product in high-D space directly from original features. No explicit φ(x) transformation required.
Concrete example — XOR problem
Original 2DNo line separates (0,0),(1,1) from (0,1),(1,0)
Add z = x·yNow separable with z = 0.5 plane
Kernel handles thisPolynomial k(x,y) = (x·y + 1)² implicitly
07 · Kernel menu

Kernel types

Different kernels create different boundary shapes. Choosing the right kernel determines what patterns SVM can separate.

L
Linear Kernel
›
Formula: K(xᵢ, xⱼ) = xᵢ · xⱼ

Boundary: Straight hyperplane

Best for: Linearly separable data, high-dimensional sparse text data

Speed: Fastest — no transformation needed. Always start here.
R
RBF Kernel (Radial Basis Function)
›
Formula: K(xᵢ, xⱼ) = exp(−γ ‖xᵢ − xⱼ‖²)

Boundary: Circular / spherical — can model any smooth shape

γ (gamma): High γ = small radius = wiggly boundary (overfit). Low γ = large radius = smooth boundary.

Default in scikit-learn SVC. Most versatile — try this if linear fails.
P
Polynomial Kernel
›
Formula: K(xᵢ, xⱼ) = (xᵢ · xⱼ + c)ᵈ

Boundary: Polynomial curves — parabolas, ellipses

Best for: Image processing, NLP with polynomial feature interactions

Caution: High degree = easy to overfit. Stick to d=2 or d=3.
S
Sigmoid Kernel
›
Formula: K(xᵢ, xⱼ) = tanh(γ xᵢ · xⱼ + c)

Boundary: S-shaped — similar to neural network activations

Note: Rarely outperforms RBF. Not always a valid kernel for all parameter settings.
Kernel selection guide
Start withLinear — fastest, good baseline
If linear failsRBF — most versatile
Text classificationLinear — sparse high-D is already separable
Unknown boundary shapeCross-validate RBF with different γ values

10 · Check your understanding

Quick quiz

Four questions — test yourself on SVM.

1. What are "support vectors" in SVM?
A. All training data points used to train the model

D. Vector representations of text used in NLP
Support vectors lie exactly on the margin boundaries (w·x + b = ±1). They are the only points that "support" the hyperplane — remove any non-SV training point and the hyperplane stays exactly the same. ✓
2. What happens when you increase C in a soft-margin SVM?
A. The margin gets wider — more violations are allowed
B. The margin gets narrower — fewer violations, tighter fit ✓
C. The kernel changes from linear to RBF automatically
D. The number of support vectors increases proportionally
High C = high penalty for misclassification = narrower margin, more complex boundary, risk of overfitting. Low C = allows more violations = wider margin, better generalisation. ✓
3. The kernel trick allows SVM to handle non-linear data by:
A. Drawing curved lines instead of straight hyperplanes
B. Training multiple linear SVMs and combining votes
C. Computing dot products in a higher-dimensional space without explicit transformation ✓
D. Reducing features with PCA before classification
K(xᵢ,xⱼ) = φ(xᵢ)·φ(xⱼ) computes the inner product in high-dimensional space directly from original features. The hyperplane remains linear in this high-D space — the boundary just appears curved in original space. ✓
4. Which kernel is scikit-learn SVC's default and the best first choice for non-linear data?
A. Linear kernel — fastest and simplest
B. RBF (Radial Basis Function) kernel ✓
C. Polynomial kernel with degree 3
D. Sigmoid kernel for neural-network-like boundaries
