PCA finds the directions where your data varies most, projects everything onto those axes, and keeps only the top components. More features ≠ better model. PCA proves it.

01 · The problem

The dimensionality problem

Imagine predicting placement with 10 features. Now imagine 100. Now 1000. More features doesn't automatically mean a better model — it creates serious problems.

Problems with high dimensions
Training speedSlows down drastically
OverfittingModel memorizes noise
VisualizationImpossible beyond 3D
RedundancyCorrelated features waste space
What PCA does
Reduces featuresFewer, powerful components
Preserves infoMaximum variance kept
Removes redundancyCorrelated → combined
Enables vizHigh-D data in 2D plots
Example: Study hours and library visits are both features. They're highly correlated — a student who studies a lot also visits the library often. Why keep both? PCA would combine them into one "academic effort" component.
02 · The concept

What PCA actually does

PCA is a technique that reduces the number of features while keeping maximum information. It does this by creating new features that are mathematical combinations of the old ones.

Key insight: Variance = Information. The more a feature varies across your data, the more information it carries. PCA finds the directions of maximum variance and keeps those.
Student Skills example
4 features → 2 principal components
Original featuresHidden patternPCA component
Math score + Physics scoreBoth measure analytical/science abilityPC1 — Science strength
English score + History scoreBoth measure verbal/humanities abilityPC2 — Arts strength

PCA didn't "know" about Science vs Arts. It mathematically found that Math & Physics move together, and English & History move together. The correlation structure revealed the hidden components automatically.

PC1 = 0.7(Math) + 0.7(Physics) + 0.1(English) + 0.1(History)
PC2 = 0.1(Math) + 0.1(Physics) + 0.7(English) + 0.7(History)
03 · Visual intuition

The camera angle analogy

Think about taking a photo of a crowd. If you take the photo from the wrong angle, people overlap and you can't see individual faces. Rotate the camera slightly, and you capture everyone spread out.

PCA = finding the best camera angle. It rotates the axes to align with the direction where data spreads most. The first axis (PC1) captures maximum spread. The second (PC2) captures the next most spread in a perpendicular direction.
● Original data points  |  — PC1 (max variance direction)  |  — PC2 (perpendicular to PC1)

After PCA (1D is enough)

Result2D → 1D with minimal loss
04 · The process

PCA in 5 steps

1
Standardize the data
Apply Z-score normalization so all features have mean=0 and std=1. PCA is sensitive to scale — if one feature has larger values, it will dominate the components. Standardization ensures fairness.
2
Compute the covariance matrix
Calculate how every pair of features moves together. High covariance between Math & Physics means they're correlated — redundant information. The covariance matrix captures all these relationships in one place.
3
Find eigenvectors & eigenvalues
Eigenvectors are the directions (axes) of maximum variance. Eigenvalues are the amounts of variance in each direction. Think of eigenvectors as "the best camera angles" and eigenvalues as "how much you can see from each angle."
4
Sort by eigenvalue — pick top k
Sort eigenvectors from largest eigenvalue to smallest. The largest eigenvalue = PC1 (most important direction). Choose the top k components that explain most of the variance (usually 90–95% is enough).
5
Project data onto new axes
Multiply the original data by the selected eigenvectors. Now each data point is represented in the new coordinate system. You've gone from n features → k components, keeping maximum information.
PCA = Standardize → Covariance → Eigenvectors → Sort & select → Project
05 · The math (demystified)

Eigenvectors & Eigenvalues — don't panic

The math equation looks scary: Σ · v = λ · v. Let's break it down simply.

Eigenvector (v)

A direction in your data

A unit vector pointing in a direction where the data has maximum spread. Not a specific data point — a direction. PC1 is the eigenvector with the largest eigenvalue.

ConceptuallyBest camera angle
Number of themEqual to # of features
Eigenvalue (λ)

How much variance in that direction

A scalar number representing how much data is spread along its corresponding eigenvector. Larger eigenvalue = more information in that direction.

ConceptuallyHow much you can see from that angle
UseSort to decide which PCs to keep
Don't panic at the math. For exams, you need to understand conceptually: eigenvectors = directions of maximum variance, eigenvalues = amount of variance in each direction. Sorting eigenvalues gives you PC1, PC2, etc.

python · sklearn
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# Step 1: Standardize
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)  # X has 4 features

# Step 2–5: PCA (reduce to 2 components)
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

# See how much variance each PC explains
print(pca.explained_variance_ratio_)
# e.g. [0.82, 0.14] → PC1=82%, PC2=14%, total=96%

11 · Practical guide

When to use PCA — and when not to

✓ Use PCA when
Many correlated featuresIdeal
High dimensional data (100+)Perfect
Need visualization in 2D/3DCommon use
Model training is too slowSpeed boost
Image / text dataVery common
✗ Avoid PCA when
Feature interpretability neededPCs lose meaning
Very few features (2–5)No benefit
Non-linear relationshipsUse Kernel PCA
Features are already independentNo redundancy to remove
Important: After PCA, PC1 is not "CGPA." It's something like 0.4(CGPA) + 0.3(Internals) + 0.2(Study hours)... The components lose their original meaning. If a stakeholder needs to understand "which exact features matter," PCA makes this impossible to explain directly.
Use casePCA appropriate?Why
Image compression (10,000 px)✓ YesHigh dim, no need to explain individual pixels
Face recognition✓ YesEigenfaces — famous PCA application
Placement prediction (explain to HR)✗ NoHR needs to know "which feature matters" — PCs lose this
Visualizing 50-feature student data in 2D✓ YesReduce to 2 PCs just for visualization
Genomics (1000+ gene features)✓ YesMassively high dimensional, correlated features
