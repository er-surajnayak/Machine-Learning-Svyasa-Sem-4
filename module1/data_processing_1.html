Discretization, normalization, and one-hot encoding — the three techniques that convert messy raw data into clean, model-ready numbers. Without these, even the best algorithm fails.

01 · Technique 1

Discretization — binning continuous values

Continuous → Categories

Big word. Simple idea. Discretization means converting continuous numerical values into meaningful categories (bins).

Analogy: You scored 78 marks. Instead of using the exact number, we say "Good" (61–80 range). We've converted a continuous value into a discrete category. That's discretization.
Marks → Grade bins
Original marksBin rangeLabel
320 – 40Fail
4741 – 60Average
7661 – 80Good
8981 – 100Excellent
Trade-off: Discretization reduces noise and simplifies patterns, but you lose information. A student scoring 60 and one scoring 41 both become "Average." Precision is reduced deliberately.
python · pandas
import pandas as pd

df = pd.DataFrame({"Marks": [35, 67, 89, 45, 72, 91, 58]})

df["Grade"] = pd.cut(df["Marks"],
               bins=[0, 40, 60, 80, 100],
               labels=["Fail", "Average", "Good", "Excellent"])
02 · Discretization types

4 types of binning

Categories are not chosen randomly. There are four different strategies depending on the data and goal.

Equal Width

Divide by value range

Split the full range into equal-sized intervals. With marks 0–100 and 5 bins: each bin is 20 marks wide (0–20, 21–40…)

Pandas codepd.cut(df, bins=4)
⚠ LimitationIgnores data distribution
Equal Frequency

Divide by data count

Each bin gets roughly the same number of data points. 100 students, 4 bins → 25 students per bin. Also called quantile binning.

Pandas codepd.qcut(df, q=4)
✓ Best forBalanced representation
Domain-Based

Expert-defined thresholds

Bins defined by domain knowledge, not math. Blood pressure: <90=Low, 90–120=Normal, 121–139=Elevated, 140+=High — medically defined.

ExampleMedical, financial, legal
✓ Best forWhen meaning matters
Model-Based

Algorithm finds optimal splits

Decision trees automatically find the best split point. Instead of 0–40=Fail, it might discover Marks>52.5 = likely Pass. Data-driven, not manual.

ExampleDecision Tree splits
✓ Best forUnknown optimal thresholds
TypeBased onWhen to use
Equal WidthValue rangeSimple cases, quick exploration
Equal FrequencyData distributionBalanced segmentation, rankings
Domain-BasedExpert knowledgeHealthcare, finance, credit scores
Model-BasedAlgorithm optimizationTree models, unknown thresholds
03 · Technique 2

Min-Max Normalization

Rescales to 0 – 1

The problem: CGPA ranges 0–10 but Salary ranges 0–10,00,000. The model sees bigger numbers as more important — Salary dominates unfairly. Normalization fixes this by bringing everything to the same scale.

Analogy: Imagine a race where one player is 6 ft tall and another suddenly becomes 60 ft. The game is unfair. Normalization makes sure everyone plays at the same scale. 🏃
Xnorm = (X − Xmin) / (Xmax − Xmin)
Worked example — CGPA 8.5, range 5–10
StepCalculationResult
X (original)8.5—
X_min5.0 (minimum CGPA)—
X_max10.0 (maximum CGPA)—
Numerator8.5 − 5.03.5
Denominator10.0 − 5.05.0
Normalized3.5 / 5.00.7
python · sklearn
from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler()
df["CGPA"] = scaler.fit_transform(df[["CGPA"]])
# All values now between 0 and 1
When it's important: KNN, SVM, Neural Networks — models that compute distances or use gradient updates. A feature with large values will dominate unless normalized.
04 · Normalization variant

Z-Score Standardization

Centers at mean=0, std=1

Min-Max squeezes values between 0 and 1. But what if a new extreme outlier appears later? The whole scale shifts. Z-Score is more robust — it measures how many standard deviations a value is from the mean.

Z = (X − μ) / σ     where μ = mean, σ = standard deviation
Worked example — Salary data
Mean salary = ₹6,00,000 · Std deviation = ₹1,00,000
SalaryFormulaZ-ScoreMeaning
₹4,00,000(4L − 6L) / 1L−2.02 std below average
₹5,00,000(5L − 6L) / 1L−1.01 std below average
₹6,00,000(6L − 6L) / 1L0.0Exactly average
₹7,00,000(7L − 6L) / 1L+1.01 std above average
₹8,00,000(8L − 6L) / 1L+2.0Significantly above
Analogy: Instead of saying "You scored 80 marks," we say "You scored 1.5 standard deviations above the class average." Now we understand performance relative to the group. That's Z-Score thinking.
python · sklearn
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
df["Salary"] = scaler.fit_transform(df[["Salary"]])
# Mean becomes 0, std becomes 1
05 · Comparison

Min-Max vs Z-Score — when to use which

Min-Max
Output range0 to 1 (fixed)
Centered at 0?No
Outlier sensitivityHigh — outliers shift scale
Based onMin & Max values
Best forImage pixel values, bounded features
Z-Score
Output rangeNo fixed range
Centered at 0?Yes — mean becomes 0
Outlier sensitivityLower — based on mean/std
Based onMean & Std deviation
Best forLogistic regression, SVM, PCA
Rule of thumb: If you don't know which to use — start with Z-Score. It's more stable and works better for most ML algorithms. Use Min-Max when the algorithm specifically needs values between 0 and 1 (e.g., neural network output layers).

07 · Technique 3

One-Hot Encoding

Categorical → Binary columns

Categorical features can't be numbered directly (CSE=1, ECE=2 implies a ranking that doesn't exist). One-Hot Encoding solves this by creating one binary column per category.

The problem with simple numbering: If Branch: CSE=1, ECE=2, MECH=3 — the model learns MECH > ECE > CSE mathematically. But branches have no ranking! The model learns a false relationship.
Original vs One-Hot Encoded

❌ Wrong approach

BranchStudent
CSE = 1Arjun
ECE = 2Priya
MECH = 3Rahul

Model thinks MECH(3) > ECE(2) > CSE(1)

✓ One-Hot Encoding

CSEECEMECH
100
010
001

No ranking implied. Just identity.

python · pandas (recommended)
df = pd.DataFrame({"Branch": ["CSE", "ECE", "MECH", "CSE"]})
df_encoded = pd.get_dummies(df, columns=["Branch"])
# Creates Branch_CSE, Branch_ECE, Branch_MECH columns
⚠ Curse of dimensionality: If you have 100 unique cities, one-hot encoding creates 100 new columns. For very high-cardinality features, consider target encoding or embedding instead.
