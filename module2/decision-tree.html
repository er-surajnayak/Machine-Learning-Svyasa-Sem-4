Decision Tree —
Entropy & Gini

How a machine plays 20 questions to classify data — and the mathematics behind choosing the right question every time. From Akinator to cancer diagnosis.

01 · The concept

What is a Decision Tree?

You've probably played Akinator — the genie who guesses your character by asking yes/no questions. "Is it a real person?" → "Is she a woman?" → "Is she a singer?" It narrows things down with each question until it arrives at an answer. That's exactly what a decision tree does.

Analogy — The Akinator Game: A decision tree learns which questions to ask (which features to split on) and in what order — so it can classify any new data point by walking it down the tree from root to leaf, answering one question at a time.
Structure

Leaf nodesFinal class predictions
Properties

InterpretabilityVery high — see every decision

EXAMPLE — SHOULD I WATCH THIS MOVIE?

The tree walks every movie through the same questions and arrives at a prediction. Now the real question is — how does it decide which question to ask first? That's where entropy comes in.

02 · The core idea

How the tree chooses splits

The tree tries every possible feature and every possible split point. For each one, it asks: "Does splitting here make my data more organised?" The split that creates the purest child nodes — where each side contains mostly one class — is chosen.

Analogy — Sorting a messy sock drawer: Imagine sorting a pile of mixed red and blue socks. You could sort by size — but maybe big socks are still mixed. Or you could sort by colour — and suddenly each pile is pure (all red or all blue). The tree picks the sorting rule that creates the least-mixed piles. Purity = low entropy.

Two mathematical measures quantify this purity: Entropy (used by ID3 algorithm) and Gini Impurity (used by CART). Both measure the same thing — how mixed a node is — just with slightly different maths.

03 · Measuring disorder

Entropy explained

Entropy comes from information theory. It measures the amount of uncertainty or disorder in a set. A perfectly pure set has entropy 0. An evenly mixed set has maximum entropy.

Analogy — Three jars of marbles: Jar A has 10 green marbles — reach in blindfolded, you always know what you'll get. Zero surprise. Entropy = 0. Jar B has 5 green and 5 red — total uncertainty. Maximum surprise. Entropy = 1. Jar C has 8 green, 2 red — mostly predictable with some uncertainty. Entropy = 0.72. Entropy measures that surprise.
Jar A — Pure
H = 0.00
10 Yes, 0 No
Zero confusion
Jar B — Mixed
H = 1.00
5 Yes, 5 No
Maximum confusion
Jar C — Mostly Yes
H = 0.72
8 Yes, 2 No
Some confusion
H(S) = − Σ p(i) × log₂(p(i))
Binary case: H = −p(Yes)·log₂(p(Yes)) − p(No)·log₂(p(No))
Why log base 2? Entropy comes from information theory where information is measured in bits. Log₂ tells us "how many binary yes/no questions are needed to remove this uncertainty?" Entropy = 1 means one binary question resolves everything. Entropy = 0 means no question needed.
Quick calculation — Jar B (5 Yes, 5 No, Total = 10)
p(Yes) = 5/10= 0.5
p(No) = 5/10= 0.5
H = −(0.5 × log₂0.5) − (0.5 × log₂0.5)= 1.00
MeaningMaximum uncertainty — must split
04 · Measuring improvement

Information Gain

Entropy alone tells us how mixed a node is. Information Gain tells us how much a split improves things — how much entropy is reduced after splitting on a feature.

Analogy — The best question in 20 Questions: You're playing 20 Questions. You could ask "Is it alive?" — which might immediately split the options into two roughly equal groups. Or you could ask "Is it a species of beetle?" — which narrows almost nothing for most answers. Information Gain measures which question reduces your confusion the most. The tree always picks the highest-gain question.
Information Gain (IG) = H(parent) − Σ [ (|Sᵥ| / |S|) × H(Sᵥ) ]
= Entropy before split − Weighted entropy after split
High IG → Good split
Parent entropy1.00 (very mixed)
After split0.20 (nearly pure)
Information Gain0.80 — excellent
DecisionUse this feature first
Low IG → Bad split
Parent entropy1.00 (very mixed)
After split0.95 (still mixed)
Information Gain0.05 — useless
DecisionTry another feature

06 · Alternative measure

Gini Impurity

Gini impurity is the measure used by the CART algorithm (Classification and Regression Trees). It asks: "If I randomly pick two samples from this node, what's the probability they belong to different classes?"

Analogy — The Random Draw Test: Reach into a jar and pull out two marbles at random. If they're always the same colour → Gini = 0 (pure). If they're often different colours → high Gini (impure). Gini measures the chance of a wrong classification if you randomly assigned labels.
Gini(S) = 1 − Σ p(i)²
Binary case: Gini = 1 − p(Yes)² − p(No)²
Pure node
p(Yes) = 1.0p(No) = 0.0
Gini = 1 − 1² − 0²= 0.00
MeaningPerfectly pure
Maximum impurity
p(Yes) = 0.5p(No) = 0.5
Gini = 1 − 0.25 − 0.25= 0.50
MeaningMost mixed possible
Partial purity
p(Yes) = 0.8p(No) = 0.2
Gini = 1 − 0.64 − 0.04= 0.32
MeaningMostly pure

Like entropy, Gini impurity is calculated for each potential split. The split with the lowest weighted Gini across child nodes is chosen. The formula for splitting:

Gini Gain = Gini(parent) − Σ [(|Sᵥ| / |S|) × Gini(Sᵥ)]
07 · Head to head

Entropy vs Gini Impurity

Both measure node purity. Both produce very similar trees in practice. The differences are subtle but worth knowing.

H
Entropy (Information Gain)
›
Formula: −Σ p(i) × log₂(p(i))
Range: 0 (pure) to log₂(n_classes) — 1.0 for binary
Used by: ID3, C4.5 algorithms
Computation: Slightly slower — involves logarithm
Behaviour: Penalises impurity more strongly for extreme class distributions
Best when: You want to explore more balanced trees or have multiple classes
G
Gini Impurity
›
Formula: 1 − Σ p(i)²
Range: 0 (pure) to 0.5 for binary — (1 − 1/n_classes) max
Used by: CART algorithm (sklearn default)
Computation: Faster — only squaring, no logarithm
Behaviour: Tends to isolate the most frequent class into one branch
Best when: You want speed and the dataset is large
Practical comparison
Result similarityBoth produce nearly identical trees ~95% of time
SpeedGini is faster (no log calculation)
Default in scikit-learnGini (use criterion='entropy' to switch)
MulticlassBoth handle it — entropy slightly preferred
Exam tipEntropy = theory / ID3. Gini = implementation / CART
08 · The problem

Overfitting & Pruning

Left unchecked, a decision tree will keep splitting until every leaf has exactly one sample — 100% training accuracy. But on new data? It fails completely. It has memorised the training set instead of learning from it.

Analogy — The Overstudied Student: A student memorises every question and answer from last year's exam paper word for word. They score 100% on that exact paper. But the moment a question is slightly rephrased, they're lost — they learned the answers, not the concepts. An overfit tree does the same thing.
Overfitting symptoms
Training accuracyVery high (near 100%)
Test accuracyMuch lower
Tree depthVery deep
Leaf samples1–2 per leaf
Solutions
max_depthLimit tree depth
min_samples_leafMin samples per leaf
min_samples_splitMin samples to split
Pruning (post)Remove low-gain branches after building
from sklearn.tree import DecisionTreeClassifier

model = DecisionTreeClassifier(
    criterion='entropy',    # or 'gini'
    max_depth=5,           # prevent over-deep trees
    min_samples_leaf=10    # at least 10 samples per leaf
)
model.fit(X_train, y_train)

10 · Check your understanding

Quick quiz

Four questions — test yourself on decision trees.

1. A node contains 6 Yes and 0 No samples. What is its entropy?
A. 1.0 — maximum entropy
B. 0.0 — perfectly pure ✓
C. 0.5 — half mixed
D. 0.6 — mostly pure
All samples belong to one class → p(Yes)=1, p(No)=0. H = −1×log₂(1) − 0 = 0. A pure node has zero entropy — no splitting needed. ✓
2. Information Gain is calculated as:
A. Entropy of child nodes ÷ entropy of parent
B. Sum of all child node entropies
C. Parent entropy − weighted entropy of children ✓
D. Child entropy − parent entropy
IG = H(parent) − Σ[(|Sᵥ|/|S|) × H(Sᵥ)]. We subtract weighted child entropy from parent entropy. A higher result means the split reduced confusion more. ✓
3. Gini impurity of a node with 5 Yes and 5 No (Total = 10) is:
A. 1.0 — same as entropy
B. 0.5 — maximum Gini ✓
C. 0.25 — quarter impure
D. 0.0 — perfectly pure
Gini = 1 − p(Yes)² − p(No)² = 1 − 0.5² − 0.5² = 1 − 0.25 − 0.25 = 0.50. Maximum Gini for binary = 0.5 (unlike entropy max of 1.0). ✓
4. Which algorithm uses Gini impurity by default?
A. ID3 — iterative dichotomiser 3
B. C4.5 — successor to ID3
C. CART — Classification and Regression Trees ✓
D. Random Forest — ensemble method
CART (used by scikit-learn's DecisionTreeClassifier) uses Gini by default. ID3 and C4.5 use entropy/information gain. You can switch sklearn to entropy with criterion='entropy'. ✓
