01 · Foundation

Sampling First — The Missing Concept

Before understanding Bagging, you must understand Sampling.

Sampling = Selecting a subset of data from a dataset. Instead of using the full data, we pick parts of it.

Two Types of Sampling

Without Replacement

Once selected → cannot be selected again.

Data = [A, B, C, D]
Sample = [A, B]
A won't repeat

Like picking cards from a deck — each card picked is removed.

With Replacement ⭐

Same data point can be selected multiple times.

Data = [A, B, C, D]
Sample = [A, B, B, D]
B appears twice, C may not

Like picking and putting the card back before the next draw.

02 · Big Picture

What is Ensemble Learning?

Instead of trusting a single model, combine multiple models to produce a single improved output.

Real-Life Analogy: One doctor is risky. Multiple doctors consulting together → more reliable diagnosis. The final decision is the combined opinion.

Single models suffer from:

Overfitting

High variance — memorises training noise

Underfitting

High bias — too simple to learn

Instability

Small data change → very different model

Ensemble methods help by: Improving accuracy, reducing errors, and increasing stability.

Exam Definition: "Ensemble learning is a technique in which multiple base models are combined to produce a single improved model with better accuracy and generalisation."

04 · Core Method

Bagging (Bootstrap Aggregating)

Definition: "Bagging is an ensemble technique where multiple models are trained independently on different bootstrap samples (sampling with replacement), and their outputs are combined using voting or averaging."

Break the Word

BootstrapSampling with replacement → creates diverse datasets
AggregatingCombining outputs of all trained models

🍕 The Pizza Analogy

Ask 1 person to rate a pizza → biased opinion. Ask 20 people → the average is far more reliable. That's Bagging!

Single Model

One biased, unstable opinion. Sensitive to training data noise.

Bagging Ensemble

20 diverse opinions averaged → stable, accurate, robust prediction.

05 · Workflow

Step-by-Step Working

1
Original Dataset D
Start with your full dataset D with N rows of training data.
2
Create Bootstrap Samples D₁, D₂, D₃…
Sample from D with replacement to create multiple datasets. Each is the same size as D, but contains different (and repeated) rows.
3
Train Independent Models h₁, h₂, h₃…
Train a separate model on each bootstrap dataset. All models are trained in parallel — they don't know about each other.
4
Predict with Each Model
Given a new input, each model makes its own independent prediction.
5
Aggregate Final Answer
ClassificationMajority Voting
RegressionAverage of all outputs
06 · The Logic

Why Bagging Actually Works

Bagging reduces Variance — the tendency of a model to fluctuate wildly based on the training data it sees.

High Variance Problem

Sensitive model trained on Dataset A gives output X. Same model trained on Dataset B gives output Y. X ≠ Y — the model is unstable!

Bagging Solution

Each model sees different data → makes different errors. When you average their outputs, the individual errors cancel each other out → stable result.

Think of it this way: If half the models overestimate and half underestimate, the average lands right in the middle — which is the correct answer!

Which Models Benefit Most?

Bagging works best for High Variance (Sensitive) Models — models that change drastically with small data changes.

Decision Trees 🌳Perfect for Bagging — highly sensitive to data
KNNAlso benefits significantly
Linear RegressionLess benefit — already low variance
07 · Real Example

Random Forest — Bagging in Action

Random Forest = Bagging + Decision Trees + Feature Randomness

It doesn't just create different data subsets (bootstrap) — it also uses a random subset of features at each tree split. This adds an extra layer of diversity.

1
Bootstrap Sampling
Create N bootstrap datasets from original data.
2
Grow Decision Trees (with Feature Randomness)
At each split in the tree, only a random subset of features (e.g., √n features) is considered. This prevents all trees from looking the same.
3
Combine via Majority Vote
For classification, the class with the most votes across all trees wins.
Reduces Overfitting

Trees vote against each other's overfit patterns

Better Accuracy

Consistently outperforms single decision trees

More Diversity

Feature randomness prevents correlated trees

08 · Theory

Bias vs. Variance — Bagging's Effect

Error TypeBagging EffectReason
Bias Stays the same Same type of model, same assumptions
Variance Decreases ↓ Averaging cancels out individual model errors
Conclusion: Bagging = Variance Reduction Technique. It does NOT fix bias. If your base model underfits, bagging won't help.
09 · Bonus Feature

Out-of-Bag (OOB) Error

When you sample with replacement, ~37% of data points are never selected in a given bootstrap sample. These are called Out-of-Bag (OOB) samples.

The Clever Part: These OOB samples act as a natural validation set! Each model can be tested on the data it never saw during training — giving you a free, unbiased error estimate without needing a separate train-test split.
OOB ErrorMean error of each tree on its OOB samples
BenefitNo need for separate validation set
Typical OOB Rate~37% of data per tree

11 · Evaluation

Advantages & Disadvantages

✔ Advantages
  • Reduces variance and overfitting significantly
  • Improves prediction stability
  • Works great with high-variance models (trees)
  • Models train in parallel — faster than Boosting
  • OOB provides free validation metric
✘ Disadvantages
  • High computation — many models to train
  • Less interpretable than a single model
  • Does not reduce bias — won't fix underfitting
  • High memory usage for large ensembles
12 · Practice

Quiz Yourself

Score: 0 / 4 correct

Q1. What type of sampling does Bagging use to create bootstrap datasets?
Correct! Bagging uses sampling WITH replacement (bootstrap sampling). This allows the same data point to appear multiple times in a single sample, creating diverse datasets from the same original data.
Q2. For a Classification problem, how does Bagging combine the predictions from all models?
Correct! For classification, Bagging uses Majority Voting. For regression problems, it uses averaging. The class with the most votes across all models wins.
Q3. Which error component does Bagging primarily reduce?
Correct! Bagging is a Variance Reduction Technique. It does NOT significantly change model bias. If your base model is biased (underfitting), Bagging won't fix it.
Q4. What are Out-of-Bag (OOB) samples in Bagging?
Correct! OOB samples are the ~37% of data points not selected in each bootstrap sample. They act as a free validation set — each tree is tested on its own OOB data, providing an unbiased error estimate with no extra split required.
13 · Revision

Exam-Ready Notes

Full Definition (5–8 marks)

"Bagging (Bootstrap Aggregating) is an ensemble learning technique where multiple base models are trained independently on different bootstrap samples created using sampling with replacement. Their predictions are combined using majority voting (for classification) or averaging (for regression) to reduce variance and improve model performance. It is particularly effective for high variance models such as decision trees, as seen in Random Forest."

Quick Bullet Points
  • Uses sampling with replacement (bootstrap)
  • Multiple models trained independently
  • Outputs combined via voting / averaging
  • Primarily reduces Variance
  • Example: Random Forest
  • OOB gives free validation error
  • Parallel training → computationally efficient
One-Line Intuition: "Create multiple slightly different datasets → train models → combine → get a stable prediction."
Final Mental Model: "Bagging is like asking multiple versions of the same model trained on slightly different realities… and trusting the majority decision." 🏆
