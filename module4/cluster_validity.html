Intra-Cluster
Similarity & Validity

You can form clusters — but are they actually good? This topic teaches you to mathematically verify clustering quality using cohesion, separation, silhouette score, and the Davies-Bouldin index.

01 · Motivation

Why Cluster Validation is Needed

📌 Suppose you run K-Means with K=2, K=3, and K=5. All produce clusters. But which clustering is actually better? Cluster validation answers this question.

Any clustering algorithm will happily produce clusters — the question is whether those clusters are meaningful, compact, and well-separated.

K=2
2 clusters — good?
K=3
3 clusters — better?
K=5
5 clusters — overfitting?
🧠 Classroom Analogy: Grouping students by marks. A good grouping has similar students inside each group, and clearly different groups. A bad grouping mixes everyone up.

06 · Validity Metric

Silhouette Score

📌 Most Important: The silhouette score measures how well each data point fits in its own cluster compared to other clusters.

The Two Distances

a — Intra distance

a = average distance from a point to all other points in its own cluster

Small a → point fits well in its cluster

b — Nearest-cluster distance

b = average distance from a point to all points in the nearest other cluster

Large b → point is far from other clusters

The Formula

s = (b - a) / max(a, b)
where: a = avg intra-cluster dist, b = avg nearest-cluster dist
Interpretation Range: −1 to +1
+1 (Excellent)Points well inside correct cluster
~0 (Borderline)Point on boundary between clusters
−1 (Wrong)Point assigned to wrong cluster
⭐ Exam Key: Higher Silhouette Score = Better Clustering. Range: −1 to +1.
07 · Worked Examples

Silhouette Score — 3 Cases

1
Case 1 — Excellent Cluster (s = 0.8)
a = 2 (close to own cluster), b = 10 (far from other cluster)
s = (10 − 2) / max(10, 2) = 8 / 10 = 0.8
✅ Point fits perfectly in its cluster.
2
Case 2 — Weak Cluster (s = 0.125)
a = 7, b = 8 (almost equally close to another cluster)
s = (8 − 7) / max(8, 7) = 1 / 8 = 0.125
⚠ Borderline — point could belong to either cluster.
3
Case 3 — Wrong Cluster (s = −0.67)
a = 9, b = 3 (actually closer to a different cluster!)
s = (3 − 9) / max(9, 3) = −6 / 9 = −0.67
❌ Point is misclassified — assigned to the wrong cluster.
🧠 Netflix Example: Good silhouette score means anime lovers are grouped together, thriller lovers are grouped together, and different genres are clearly separated. Poor score = random users mixed everywhere.

09 · Validity Metric

Davies-Bouldin Index (DBI)

📌 Definition: The Davies-Bouldin Index measures how similar each cluster is to its most similar neighboring cluster. It considers both cluster scatter and inter-cluster distances.

Core Formula Idea

DBI = (1/K) × Σ max[j≠i] ( (σᵢ + σⱼ) / d(cᵢ, cⱼ) )
σᵢ = scatter of cluster i · d(cᵢ,cⱼ) = distance between centroids
🧠 Intuition: DBI = (Cluster Scatter) / (Distance Between Clusters). Small scatter + large separation = small DBI = better clustering.
📉
Lower DBI
Better Clustering
Clusters are compact and well-separated
📈
Higher DBI
Poor Clustering
Clusters overlap or are scattered
⚠ Common Exam Mistake: Silhouette = Higher is Better. DBI = Lower is Better. Students often confuse these!
MetricBetter ValueWhat it Measures
Silhouette ScoreHigher (+1)Individual point fit quality
Davies-Bouldin IndexLower (→ 0)Overall cluster compactness vs separation
🧠 Canteen Analogy: Good grouping = friends sit close together (low scatter), different friend groups sit separately (high separation). DBI mathematically measures this tendency.
10 · External Measures

External Validity Measures

📌 Internal measures use only the dataset itself. When we already know the true labels, we can compare clusters to actual classes using external measures.

Example Scenario

Actual labels: Cats vs Dogs
Algorithm produces: Cluster 1 vs Cluster 2
External validity compares predicted clusters to actual classes.

Common External Measures

MeasurePurpose
PurityWhat fraction of each cluster belongs to the dominant class?
Rand IndexMeasures agreement between clustering and true labels (like accuracy for clustering)
F-MeasureCombines precision and recall — considers both false positives and negatives
🧠 Real Tech Use: Spam email detection (actual spam/non-spam labels known), recommendation system evaluation, and customer segmentation testing.

12 · Evaluation Flow

Complete Clustering Evaluation Flow

1
Run Clustering Algorithm
Apply K-Means or Hierarchical clustering to your dataset.
2
Form Clusters
Assign each data point to a cluster.
3
Measure Cohesion
Calculate average intra-cluster distance for each cluster.
4
Measure Separation
Calculate distance between cluster centroids / borders.
5
Apply Validation Metrics
Compute Silhouette Score and/or Davies-Bouldin Index.
6
Choose Best Clustering
Pick the K or algorithm that gives highest silhouette / lowest DBI.
13 · Revision

Short Exam Note

  • Cohesion = intra-cluster similarity; points within cluster should be close
  • Separation = inter-cluster dissimilarity; different clusters should be far apart
  • Good Clustering = High Cohesion + High Separation
  • Silhouette Score formula: s = (b − a) / max(a, b)
  • Silhouette range: −1 to +1; Higher is Better
  • Davies-Bouldin Index: ratio of scatter to separation; Lower is Better
  • Internal measures: use dataset properties (Silhouette, DBI)
  • External measures: use true labels (Rand Index, Purity, F-Measure)
🧠 Memory Tricks
  • Cohesion: "Same group stays close"
  • Separation: "Different groups stay far"
  • Silhouette: "Higher is Happier"
  • DBI: "Lower is Better"
⭐ Viva Questions
  • What is cohesion? → Intra-cluster similarity
  • What is separation? → Inter-cluster distance
  • Silhouette range? → −1 to +1
  • Better DBI? → Lower value
  • Internal vs External? → No labels vs labels
14 · Practice

Quiz Yourself

Score: 0 / 6 correct

Q1. What does "cohesion" measure in cluster validation?
Correct! Cohesion measures intra-cluster similarity — how close points within the same cluster are to each other. High cohesion = compact, tight clusters.
Q2. In the silhouette formula s = (b − a) / max(a, b), what does "a" represent?
Correct! a is the average distance from a point to all other points in its own cluster. Small a means the point is well placed inside its cluster.
Q3. A data point has silhouette score = −0.67. What does this indicate?
Correct! A negative silhouette score means the point is closer to another cluster than its own — it has been misclassified. The score of −0.67 is a strong signal of wrong cluster assignment.
Q4. Which statement about the Davies-Bouldin Index (DBI) is correct?
Correct! For DBI, Lower is Better. DBI measures the ratio of cluster scatter to inter-cluster distance — a low value means compact, well-separated clusters.
Q5. When do we use External Validity Measures for clustering evaluation?
Correct! External validity measures like Rand Index, Purity, and F-Measure require true class labels. They compare the clustering output against the ground truth to evaluate quality.
Q6. What is the ideal clustering outcome in terms of cohesion and separation?
Correct! The ideal cluster has High Cohesion (points are tight within the cluster) AND High Separation (clusters are clearly far from each other). This is the gold standard of cluster validity.
