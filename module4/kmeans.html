01 · Introduction

What is Clustering?

📌 Definition: Clustering is an unsupervised learning technique used to group similar data points into clusters such that:
  • Data points in the same cluster are similar.
  • Data points in different clusters are dissimilar.

🧠 Intuition

Imagine you open Spotify. It groups songs into: Chill, Workout, and Party.

👉 No one told Spotify the labels for these songs — it figured out the patterns on its own based on tempo, energy, and acousticness. That’s clustering.

💻 Tech Examples

E-commerce (Amazon)

Groups users into Budget buyers, Premium buyers, and Frequent shoppers based on purchase history.

Netflix

Clusters users with similar viewing habits to recommend relevant content.

📌 Types of Clustering

  • Partitional Clustering → K-Means
  • Hierarchical Clustering → Agglomerative & Divisive
02 · Strategy

What is Partitional Clustering?

📌 Definition: Partitional clustering divides a dataset into K non-overlapping clusters, where each data point belongs to exactly one cluster.

👉 The goal is: High similarity within a cluster, and low similarity between different clusters.

🧠 Simple Intuition

Imagine a classroom. You divide students into 3 strict groups:

  • Coders
  • Gamers
  • Designers

👉 Each student belongs to only one group. There is no overlap. That’s partitional clustering.

03 · The Algorithm

What is K-Means?

📌 Definition: K-Means is an unsupervised learning algorithm that partitions data into K clusters, where each data point is assigned to the cluster with the nearest mean (centroid).
🧠 One-Line Intuition:
"Group data such that each point is closest to its cluster center."
04 · Core Vocabulary

Key Concepts

🔹 Cluster A group of similar data points.
🔹 Centroid The mean position of all points in a cluster. Represents the center of the cluster.
🔹 Distance Measure Used to decide closeness between a point and a centroid. Usually Euclidean Distance.
05 · Workflow

How K-Means Works

1
Choose number of clusters K
Decide how many groups you want to find.
2
Initialize K centroids randomly
Pick K random points in the data space to act as initial cluster centers.
3
Assign each data point to the nearest centroid
Calculate distance from every point to all centroids, assign point to the closest one.
4
Recalculate centroids
Find the new mean (center) of all points currently assigned to each cluster.
5
Repeat steps 3 & 4
Keep assigning and recalculating until centroids do not change (convergence).

🧠 Intuitive Example: Spotify User Clustering

Features: Listening time & Genre preference.

  • Pick 3 clusters → (K = 3)
  • Assign users to nearest group
  • Update cluster centers
  • Repeat until stable

👉 Finally: Cluster 1: Chill listeners, Cluster 2: Workout listeners, Cluster 3: Party listeners.

06 · The Math

Mathematical Objective

K-Means tries to minimize the Within Cluster Sum of Squares (WCSS).

📌 It minimizes the sum of squared distances between each point and its centroid.

👉 Meaning: Points should be as close as possible to their cluster center, keeping clusters compact and tight.

07 · Measurement

Distance Measure

K-Means relies on geometry to figure out which points belong together.

📐 Euclidean Distance

Distance between two points: 👉 Straight-line distance.

🧠 Example

User A: (2 hrs usage, ₹500 spend)
User B: (3 hrs usage, ₹700 spend)
👉 Distance tells how similar they are.

08 · Hyperparameter

Choosing Value of K — The Elbow Method

How do we know the right number of clusters?

📌 Idea: Try different values of K (e.g., 1 to 10), compute the error (WCSS) for each, and plot it.
  • 📉 Graph: X-axis → K, Y-axis → WCSS
  • 👉 Choose the point where the curve bends = “Elbow”

🧠 Intuition

  • Too small K → large, generic clusters (bad)
  • Too large K → overfitting (each point becomes its own cluster)
  • 👉 Elbow = the perfect balance
09 · Evaluation

Advantages & Limitations

✅ Advantages
  • Simple and easy to implement
  • Fast for large datasets
  • Works well when clusters are clearly separated and spherical
❌ Limitations
  • Need to choose K manually
  • Sensitive to initial centroids
  • Affected heavily by outliers
  • Works poorly with non-spherical clusters or different density clusters
10 · Pitfall

K-Means Initialization Problem

📌 Issue: Random initialization can lead to completely different results each time you run it, or it might get stuck in a bad local minimum.
💡 Solution: K-Means++
👉 Smarter centroid initialization method that spreads out the initial centers. It significantly improves performance and stability.
11 · Stopping Criteria

Convergence of K-Means

📌 When does it stop?

  • Centroids stop changing positions, OR
  • Point assignments to clusters don’t change anymore.

🧠 Intuition: 👉 Clusters have become stable.

13 · Performance

K-Means vs Real World

👉 Works well when:
Data is well-separated, and clusters are roughly circular (spherical).
👉 Fails when:
Data is irregular shape (like a smiley face or moons), or noise/outliers are high.

🧠 Real-Life Understanding of Outliers

Imagine one extreme data point far away from everyone else.
👉 It pulls the centroid towards itself because the mean is sensitive to extreme values → the whole cluster becomes wrong.

14 · Calculation

Small Numerical Example

Data Points: (1,2), (2,3), (8,9), (9,10)
Let K = 2

1
Choose centroids randomly
Pick two points.
2
Assign nearest points
Calculate distance from each point to the two centroids and assign.
3
Compute new centroid
Cluster 1: (1,2), (2,3) → new centroid ≈ (1.5, 2.5)
Cluster 2: (8,9), (9,10) → new centroid ≈ (8.5, 9.5)
15 · Revision

Short Exam Note

  • K-Means = Partitional clustering
  • Divides data into K non-overlapping clusters
  • Uses centroid (mean of points) as cluster center
  • Goal: Minimizes WCSS (Within Cluster Sum of Squares)
  • Distance Metric: Euclidean distance usually
  • Requires K to be predefined (use Elbow method)
  • Sensitive to outliers and random initialization
16 · Practice

Quiz Yourself

Score: 0 / 6 correct

Q1. What type of clustering is K-Means?
Correct! K-Means is a Partitional Clustering algorithm because it divides data into non-overlapping clusters where each point belongs to exactly one cluster.
Q2. Which mathematical objective does K-Means try to minimize?
Correct! K-Means minimizes the WCSS, meaning it wants the points in a cluster to be as tightly packed around the centroid as possible.
Q3. Which method is most commonly used to choose the optimal value of K?
Correct! The Elbow Method plots WCSS against different values of K, and you look for the "bend" to find the optimal number of clusters.
Q4. When does the K-Means algorithm stop iterating (converge)?
Correct! The algorithm stops when centroids stop changing positions or point assignments stop changing, which means the clusters have stabilized.
Q5. Which of the following is a major limitation of K-Means?
Correct! K-Means is highly sensitive to outliers because extreme values pull the mean (centroid) far away from the true center of the cluster.
Q6. What problem does the K-Means++ algorithm solve?
Correct! K-Means++ is a smarter initialization technique that spreads out the initial centroids to prevent poor clustering results from bad random starts.
